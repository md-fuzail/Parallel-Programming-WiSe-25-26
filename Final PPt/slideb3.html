// Cache-friendly i-k-j loop orderfor (int i = 0; i < my_rows; i++) {    for (int k = 0; k < n; k++) {        double a_val = local_a[i * n + k];        for (int j = 0; j < n; j++) {            local_c[i * n + j] +=                 a_val * mat_b[k * n + j];        }    }}
🧠
Spatial Locality Guarantee
By hoisting a_val and iterating over j internally, the hardware prefetcher reads mat_b linearly (stride-1). This drastically reduces L1/L2 cache misses compared to naive i-j-k loops.
