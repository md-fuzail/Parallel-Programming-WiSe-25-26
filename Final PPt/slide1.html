Slide 1: Hotspot Detection & Early Exit Strategy

Speaker : Md Fuzail
🚩  Objectives & Challenges
🎯
Goal
Terminate immediately upon finding a row with no local hotspots.
⚠️
Challenge
Standard C break is illegal in OpenMP loops. We must break a parallel loop barrier instantly without leaving zombie threads.
✅
Solution: OpenMP Cancellation
#pragma omp cancel for #pragma omp cancellation point for
🔗
Synchronization
Used #pragma omp critical to safely set early_exit and bad_row, ensuring only the first offending row is reported.
⚙️
Runtime Requirement
OpenMP disables cancellation by default for performance. We must set export OMP_CANCELLATION=true before execution.
