Slide 1:– OpenMP Task Parallelism

Speaker: Ehtesham Faraz
🔷  Strategy Overview
🔴
Problem
Compute π via numerical integration using a dynamic, load-imbalanced recursive task tree.
⚡
Approach
OpenMP task parallelism — one thread seeds the recursion via #pragma omp single; all threads steal tasks from the pool.
🌿
Recursion
Each task computes π over random steps, then spawns 1–4 child tasks until g_num_tasks is reached.
🔗
Atomics
Thread-safe accumulation of pi_sum and per-thread counters; unique task IDs via atomic capture.
✅
Key Pragmas
#pragma omp task #pragma omp single #pragma omp atomic
