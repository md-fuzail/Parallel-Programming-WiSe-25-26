📦  Data Structures
local_a Distributed
Only the slice needed is allocated: my_rows × N. Scales perfectly with node count.
mat_b (Full) Redundant Gen
No intermediate slice buffers. The full N×N matrix is generated straight into RAM using local CPU cycles.
local_c Result Buffer
Pre-initialized to zero using memset. Stores the local partial product of the multiplication.
🚀
1D Contiguous Allocation
All matrices use flat 1D arrays (malloc(rows * cols)). This prevents memory fragmentation, eliminates pointer-chasing, and guarantees cache locality.
⚙️  Zero-Comm Strategy
🎯
Network Bypass
By abandoning collective communication completely, the cluster network bandwidth consumption is strictly zero during startup.
🔑
Offset Math
Nodes use my_row_start + i to independently seed the RNG. This guarantees all nodes compute the exact correct slice of Matrix A.
⚠️
Constraint: Master Memory
Rank 0 must allocate a massive final mat_c (N×N) array just before MPI_Gatherv to receive and checksum the data.
