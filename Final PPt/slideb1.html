🔷  Approach : 1D Row Wise Decomposition
🏃
SPMD Approach
Single Program, Multiple Data. Each rank executes the same multiplication logic on its assigned row slice.
🔴
Load Balancing
If n % size != 0, rows cannot be evenly divided. Some ranks will naturally be assigned more work than others.
⚡
My Solution
Base rows: n / size
The first remainder processes receive exactly 1 extra row.
rows_per_proc = n / size + (i < remainder ? 1 : 0);
✅
Why This Is Balanced
  • Negligible Imbalance: Maximum difference between any two processes is at most 1 row. For large n (e.g., 8000), this is mathematically insignificant.
  • No Idle Time: Ensures an incredibly even workload distribution.
  • Good Scalability: Prevents faster nodes from idling at the final implicit barrier.
